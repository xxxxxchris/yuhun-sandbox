# 御魂沙盒（阴阳师）

网页：https://xxxxxchris.github.io/yuhun-sandbox/

玩家自制的非官方小工具，和网易无关。

- **御魂**：6 星御魂随便买、随便强化。主属性、副属性和强化成长按游戏客户端配置表里的规则随机，副属性满 4 条后提升哪条按实测的「出现次数加权」（中过的更容易再中，可切回各 1/4）；可以自定义套装、主属性、每条副属性的数值和每一级强化命中哪条，一次创建任意件数；批量强化后有统计。
- **召唤**：限时 UP（阶段概率、60 抽必出、保底）、常驻召唤、十连十金，抽完有统计画像。
- 存档只保存在你自己的浏览器里（IndexedDB），可以导出 / 导入 json。

数据取自游戏客户端配置表，页面右上角写着日期。整个网站就是一个 `index.html`，网页本身不上传任何数据（只从 Google Fonts 加载字体，连不上就用系统字体）。
